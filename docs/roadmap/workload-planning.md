# Расчёт и оптимизация недельной нагрузки

[← Идеи и направления](README.md)

**Статус:** идея, обсуждение требований. Второе направление развития EduLOG.
Реализация ещё не начата.

## Пользователи и задача

Сотрудник учебной части загружает файл плана с недельной нагрузкой
(например, «планы.txt»). Обычно значения часов по неделям в нём ещё не
расставлены. Модуль должен рассчитывать и заполнять эти значения
с учётом правил распределения.

Это отдельное направление и возможный мини-продукт внутри EduLOG.

## Основной сценарий

1. Загрузить исходный TXT-файл плана.
2. Задать или выбрать правила распределения нагрузки.
3. Рассчитать распределение часов по неделям.
4. Просмотреть заполненный недельный план и оценить результат.

Способ сохранения, публикации и экспорта результата ещё предстоит согласовать.

## Что уже определено

- Входные данные — существующий файл плана с недельной нагрузкой в формате TXT.
- Основной случай — план, в котором числа часов по неделям ещё не расставлены.
- Результат — заполненные значения недельной нагрузки.
- Распределение должно учитывать правила.
- Цель — оптимальное распределение; конкретный критерий оптимальности
  пока не определён.

## Правила и критерий оптимальности

Список правил предстоит собрать с пользователем. Конкретные ограничения,
приоритеты и целевая функция пока не согласованы.

При описании правил полезно разделить:
- обязательные ограничения, которые результат обязан соблюдать;
- предпочтения, по которым выбирается лучший из допустимых вариантов.

Это предложение по организации требований, а не утверждённый набор правил.
Метод и алгоритм расчёта выбираем после уточнения правил и данных.

## Связи с EduLOG

Модуль использует существующий импорт плана и представление недельной нагрузки.
Связь рассчитанной нагрузки с составлением расписания нужно уточнить отдельно.

## Открытые вопросы

- Нужно ли сохранять уже заполненные вручную значения при расчёте?
- Как сохранять и выгружать рассчитанный план?
