# Редактор расписания и экспорт в исходный JSON

[← Идеи и направления](README.md)

**Статус:** обсуждение. Первое зафиксированное направление; реализация ещё не начата.

## Пользователи и задача

Сотрудник образовательной организации загружает имеющееся расписание,
исправляет его в EduLOG, публикует устраивающий вариант и скачивает JSON,
который организация может разместить у себя.

## Основной сценарий

1. Загрузить файл расписания, например «Первый семестр.json».
2. Отредактировать расписание на основе загруженных данных:
   изменить формулировки и переставить занятия.
3. Проверить получившийся вариант.
4. Опубликовать согласованный вариант в EduLOG.
5. Отметить галочками недели для выгрузки.
6. Скачать опубликованный вариант выбранных недель в формате исходного JSON
   для размещения в образовательной организации.

## Ключевое требование: совместимость формата

Экспорт должен сохранять структуру и смысл полей загружаемого формата.
Это файл расписания, совместимый с исходным, а не выгрузка внутреннего
состояния приложения.

Неизменённые данные и поля исходного файла должны сохраняться.
Скачанный файл должен повторно загружаться в EduLOG и воспроизводить
отредактированное расписание. Побайтовое совпадение, пробелы и отступы
не являются целью: важна совместимость данных и структуры.

## Выбор недель для экспорта — согласовано

Перед скачиванием JSON пользователь выбирает недели галочками.
За основу интерфейса берём существующий выбор при печати зачётов.

- Можно отметить одну текущую неделю или несколько нужных недель.
- Чтобы выгрузить весь семестр, отмечаем все его недели.
- В JSON попадают только выбранные недели, каждая целиком.
- Исходный формат JSON сохраняется независимо от количества выбранных недель.

## Минимальная полезная версия

- Изменение формулировок в занятиях.
- Перенос и перестановка занятий.
- Предварительная проверка результата перед публикацией.
- Публикация изменённого расписания.
- Выбор экспортируемых недель галочками по аналогии с печатью зачётов.
- Скачивание JSON выбранных недель, соответствующего опубликованному варианту.

## Связи с EduLOG

Используются существующие данные расписания, группы, преподаватели и аудитории.
Публикацию следует связать с существующими ролями и правами доступа.
Нужно учесть текущее хранение расписания по неделям.
